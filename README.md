# Infrastructural power – figurgenerator

Webapp der genererer figur 1–4 til artiklen ud fra det opdaterede Excel-datasæt (ark: *AI project*, *filterartikel*, *Vendor*, *Bridging*).

Upload .xlsx-filen på siden. Filen behandles kun lokalt i browseren og sendes ikke nogen steder hen. Repoet indeholder ingen data.

Fælles reference (special issue call, Natali Helberger): https://link.springer.com/collections/jcjiaidjjj
